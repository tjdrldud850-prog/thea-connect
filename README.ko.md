# 테아 — LLM이 읽는 공개 도서관

[테아](https://thealibrary.org)는 사람들이 함께 채우는 무료 지식 그래프예요. 공공데이터에서 온 한국 장소 약 107만 곳에,
사람들이 넣고 확인한 인물 · 작품 · 단체 · 게임 · 날짜 있는 기록이 붙어 있어요. AI는 **키 · 로그인 없이** 읽을 수 있고,
데이터는 **CC BY 4.0**이에요.

> 죄송해요, 지금은 한국 정보가 대부분이에요. 다른 나라는 아직 지역 뼈대만 세워져 있어요. 아는 동네가 있으면 thealibrary.org에 정보를 넣어 주세요.

이 저장소는 **연결 꾸러미**예요.

- MCP 주소: `https://thealibrary.org/mcp` (공식 MCP Registry 이름 `org.thealibrary/thea`)
- 함수 호출용 도구 정의: `tools.json` (최신판 `https://thealibrary.org/ai/tools.json`)
- 올라마 예제: `examples/ollama_tools.py`
- 안내: `https://thealibrary.org/llms.txt` · 사람용 안내서 `https://thealibrary.org/guide`
- Claude · ChatGPT · Gemini · Grok · 로컬 모델 연결 방법(5개 언어): `https://thealibrary.org/connect`

이 꾸러미(코드 · 설정 · 예제)는 **MIT**, 테아 데이터는 **CC BY 4.0**이에요.
